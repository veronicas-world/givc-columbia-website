# Member LinkedIn review

This document tracks public LinkedIn profiles for the 56 people in the full roster. On 2026-10-14 the chapter supplied exact URLs for its six board members in `GIVC Board members.pdf`, then supplied 25 additional member names, schools and class years. The six board URLs are approved and appear on their board cards. Board members do not repeat in the general directory, whose 50 members remain pending. The 25 new members have not been researched. Approved URLs live in `approvedMemberLinkedIns` in `src/content/members.ts`; research candidates never go live without chapter approval.

## How this was researched

- Research date: 2026-10-13.
- The original 31 members were searched with public web search using only the public roster fields: name, school and class year (for example `Kagan Levine Barnard College LinkedIn`). When the first query returned nothing useful, a second exact-name query was run. No searches have been run for the 25 supplemental members.
- No private contact fields (emails, phone numbers, UNIs), join dates or internship histories were used in queries or recorded here. No LinkedIn login, private-page scraping or face matching was used. Only public search-result titles and snippets were read.
- Evidence notes are limited to name, school, study area, class-year cues and Girls Into VC affiliation. Employer and internship details shown in search snippets were deliberately left out.
- A URL is listed only when it appeared in a real search result or was supplied by the chapter. No URL was guessed or constructed.

## Status meanings

- `likely`: one public profile matches the name and school, with no competing Columbia or Barnard profile found. Still needs confirmation.
- `low-confidence`: a profile matches the name and Columbia, but the school, class year or identity is not confirmed.
- `ambiguous`: more than one plausible profile was found, and the public evidence does not settle which one is correct.
- `unknown`: no defensible LinkedIn profile was found after a real attempt.
- `supplied`: the chapter supplied the exact profile URL, replacing any earlier research candidate.
- `not-researched`: the chapter supplied the member's public roster details, but no profile research has been done.

Each row records approval status `approved` or `pending`.

## Approving a link

1. Confirm the exact URL with the member.
2. Add `'<exact roster name>': '<https://www.linkedin.com/in/...>'` to `approvedMemberLinkedIns` in `src/content/members.ts`.
3. Run `npm test -- --maxWorkers=1`. The tests check that approved names exist in the roster and URLs use the `https://www.linkedin.com/in/...` form.
